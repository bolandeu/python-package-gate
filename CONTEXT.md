# python-package-gate

Плагин Claude Code с навыком `cli-builder` и copier-шаблоном: заводит новые CLI-инструменты или переводит старые на единую архитектуру (Python + uv + Typer).

## Словарь

**Шаблон** (`template/`):
Copier-шаблон, из которого рождается сгенерированный проект. Версии шаблона — теги этого репозитория.
_Избегать_: скелет, boilerplate

**Сгенерированный проект**:
Пакет, созданный из шаблона; у него свой `AGENTS.md`, свой гейт и свой релизный процесс.
_Избегать_: клон, форк шаблона

**Навык `cli-builder`**:
Инструкция агенту (`skills/cli-builder/`): режимы Scaffold, Refactor, Update и публикация.

**Стандарт** (`reference/standard.md`):
Единый английский документ: каким пакет обязан быть (**Mandatory**, проверяет шаг гейта) и каким рекомендуется (**Recommended**). Разделы — по названию, не по номеру.
_Избегать_: контракт формы, конвенции, §N

**Три имени**:
`package_name` (импорт, keychain, префикс env, каталог), `cli_name` (команда), `dist_name` (`[project] name`, по умолчанию `rb-<slug>`).

**Опциональная часть**:
Часть шаблона, включаемая вопросом copier (`include_project`, `include_auth`, `include_providers`, `include_http_provider`, `include_db`, `include_skill`, `include_describe`, `include_contracts`), а не удалением файлов. В новом пакете выключена; пакет, созданный до появления вопроса, сохраняет её при `copier update`.

**Контракт потребителя**:
YAML в `tests/contracts/<потребитель>/` сгенерированного проекта (формат `contract: 1`): потребитель описывает, что ждёт от CLI; гейт прогоняет его отдельным шагом.
_Избегать_: интеграционный тест

**Владелец стандарта**:
Агент этого репозитория; владеет стандартом всех CLI-пакетов Человека (контракт, шаблон, релиз).

**Стандарт справки**:
Правила docstring команды: summary — первое предложение; строки `имя: текст` — только у своей опции; `Example:` — полная команда, начинается с пути команды; значение по умолчанию, допустимые значения и повторяемость — из сигнатуры.
_Избегать_: формат help

**Гейт** (`gate/`, команда `gate check`):
Проверка пакета перед выпуском и в CI: линтеры, тесты, сборка и установка колеса, обязательные правила Стандарта снаружи. Пакет запускает её через `uvx rb-gate gate check` по тегу шаблона; зависимостью пакета она не становится.
_Избегать_: ядро, библиотека-ядро, release.py
